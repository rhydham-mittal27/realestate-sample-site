# Aurelia Estates - real estate website sample

Sample site for demos. All brand names, prices, RERA numbers and contact details are fictional placeholders.

- `site.json` - all content and theme settings
- `build.js` - renders `index.html` from `site.json` (`node build.js` or `node build.js "#1F4D3A"` to restyle from one base color)
- `theme-engine.js` - derives the full palette from a single base color (OKLCH)
- Photos: Unsplash, see `assets/CREDITS.md`
